DR. ZEE WEBSITE — CPANEL STATIC SITE PACKAGE

UPLOAD
1. In cPanel File Manager, open the document root for the domain (usually public_html).
2. Upload this ZIP and choose Extract. The ZIP contains the website files at its root.
3. Confirm index.html and the assets, about, blogs, treatments and other page folders are directly inside public_html — not inside an extra dist or package folder.
4. Open the domain over HTTPS and check the home page, /blogs/, /about/ and /book-consultation/.

IMPORTANT
- This is a static HTML website package, not a WordPress theme or Elementor import.
- Back up any existing site before replacing files. Do not overwrite an existing WordPress installation unless migration is intended.
- The consultation forms are preview-only: this package does not deliver enquiries to the clinic. Connect an authorised clinic form endpoint and recipient before inviting real enquiries.
- Verify clinic credentials, contact/location details, legal notices, images and clinical content before public launch.
